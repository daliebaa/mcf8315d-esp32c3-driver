# SPEED 引脚 PWM 调速接口

本文说明如何给 MCF8315D 的 **SPEED/WAKE 引脚**直接输入一路 PWM 来控制转速，
不经过 I2C、不依赖本工程的固件。适用于把驱动板接到任意主控（STM32 / 树莓派 / PLC / 信号发生器）。

---

## 1. 接线

控制侧只需要三根线：

| 线 | 方向 | 说明 |
|---|---|---|
| SPEED | 主机 → 器件 | PWM 速度指令（本文主角） |
| nFAULT | 器件 → 主机 | 开漏，低 = 有故障。**需要上拉**（3.3V，4.7~10k） |
| FG | 器件 → 主机 | 开漏，转速脉冲。需要上拉 |

器件内部对 SPEED 有 **1MΩ 下拉**，主机侧不需要再加电阻。
DRVOFF、BRAKE 硬接地的板子上不用管；若 BRAKE 有引出，必须保持低电平（高 = 制动）。

---

## 2. 电气要求

| 项目 | 值 |
|---|---|
| 高电平门限 VIH | 0.65 × AVDD ≈ **2.15 V** |
| 允许电平 | **3.3V 或 5V 逻辑均可** |
| 绝对最大 | **6 V** |
| 输入阻抗 | 内部 1MΩ 下拉到 AGND |

> ⚠ 不要给 SPEED 超过 6V（例如直接接 12V 系统的开漏上拉）。

---

## 3. 频率：多少合适

器件侧的量程由 `SPEED_RANGE_SEL` 决定，本工程为 `0h`：

| SPEED_RANGE_SEL | 可接受的 fPWM |
|---|---|
| **0h（本工程）** | **325 Hz ~ 100 kHz** |
| 1h | 10 Hz ~ 325 Hz |

**低于 325 Hz 的 PWM 会被判为无效输入**（速度指令保持 0），这是最常见的"给了 PWM 却不转"的原因。

### 频率 vs 占空比分辨率

器件每周期对占空比采样，输入频率越高、能分辨的位数越少：

| fPWM | 占空比分辨率 |
|---|---|
| 0.01 – 2 kHz | 11 ~ 13 bit |
| 2 – 7 kHz | 11 ~ 14 bit |
| 7 – 14 kHz | 11 ~ 12 bit |
| 14 – 29 kHz | 10 ~ 12 bit |
| 29 – 60 kHz | 9 ~ 11 bit |
| 60 – 100 kHz | 8 ~ 10 bit |

**推荐 5 kHz**（本工程取值）：落在大分辨率区间，同时对占空比的采样时间也足够长。
要更细的调速就用 2~3 kHz；线束长、干扰大就用 10 kHz 左右；不建议超过 30 kHz。

> 注意：这里是**输入** PWM 的频率，和电机相线上的 **输出 PWM 载波**（本工程 55 kHz）
> 完全无关，后者由 I2C 的 `PWM_FREQ_OUT` 配置。

---

## 4. 占空比 → 转速

线性映射：**占空比 0~100% 对应 0 ~ MAX_SPEED**。

本工程 `MAX_SPEED = 600 Hz` 电频率，电机 7 对极：

```
机械转速 (RPM) = MAX_SPEED × 占空比 × 60 / 极对数
              = 600 × 占空比 × 60 / 7
              ≈ 5143 × 占空比
```

| 占空比 | 转速 |
|---|---|
| 1%（保活） | 0 |
| 20% | 1029 RPM |
| 30% | 1543 RPM |
| 40% | 2057 RPM |
| 60% | 3086 RPM |
| 80% | 4114 RPM |
| 100% | 5143 RPM |

### 底部死区

占空比低于 **max(1%, DUTY_HYS)** 时 `DUTY_CMD` 直接判为 0（手册 §6.4.1.2 表 6-7）。
实测 ≤1% 停转，20% 命令实测 1029 RPM，线性度很好。

---

## 5. 休眠：最容易踩的坑

**SPEED 脚持续为低超过 `SLEEP_ENTRY_TIME`，器件就进入休眠。**

本工程 `SLEEP_ENTRY_TIME = 3h = 200 ms`。休眠会：

- 关闭 AVDD LDO → **挂在 AVDD 上的 I2C 上拉全部失效**，I2C 彻底失联
- 关闭 buck → 板载指示灯灭
- 电机输出关闭（本来也不转）

### 两种策略

| 场景 | 做法 |
|---|---|
| **还要用 I2C**（调试 / 改参数 / 读状态） | 停机时**不要给 0% 占空比**，给 **1%** 保活。此时 DUTY_CMD 仍为 0，电机不转，但器件保持唤醒 |
| **纯自走**（只靠 SPEED 调速） | 可以直接给 0% 让它休眠，省电；下次给 PWM 自动唤醒，参数从 EEPROM 读 |

本工程固件采用第一种：停机时输出 1% 占空比。

---

## 6. 上电与唤醒时序

```
VM 上电
  │  ← 器件从 EEPROM 载入参数（几十 ms）
  ├─ 等待 ≥100 ms
SPEED 给 PWM
  │
  ├─ 若之前处于休眠：tWAKE_PWM = 3~5 ms 唤醒，期间的指令可能被忽略一次
  └─ 器件进入启动流程：对齐 → 开环加速 → 切闭环
```

实际从给 PWM 到电机稳定在目标转速约 **1~2 秒**（其中对齐 1 s 是主要耗时）。

## 7. 代码示例

### 7.1 ESP32-C3（LEDC，与本工程一致）

```c
#define SPEED_PIN   5
#define SPEED_CH    0
#define SPEED_FREQ  5000      /* 5 kHz */
#define SPEED_BITS  10        /* 0~1023 */

void speedInit(void) {
    ledcSetup(SPEED_CH, SPEED_FREQ, SPEED_BITS);
    ledcAttachPin(SPEED_PIN, SPEED_CH);
    ledcWrite(SPEED_CH, 10);          /* 1% 保活，停机 */
}

/* pct: 0.0 ~ 100.0 */
void speedSet(float pct) {
    if (pct < 1.0f) pct = 1.0f;       /* 不要给 0，否则 200ms 后休眠 */
    uint32_t max = (1u << SPEED_BITS) - 1u;
    ledcWrite(SPEED_CH, (uint32_t)(pct / 100.0f * max + 0.5f));
}
```

### 7.2 STM32（HAL，定时器 PWM）

```c
/* TIM3 CH1: PSC/ARR 配成 5 kHz，ARR = 999（1000 级，约 10 bit） */
void speedSet(float pct) {
    if (pct < 1.0f) pct = 1.0f;
    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1,
                          (uint32_t)(pct / 100.0f * 1000.0f));
}
```

### 7.3 用信号发生器快速验证

- 波形：方波，**5 kHz**，幅度 **3.3V**
- 占空比从 20% 开始试（低于 ~1% 不转属正常）
- 给 100% 前确认电机已固定、扇叶无遮挡

## 8. 与本工程配置的对应关系

| 寄存器 | 位 | 本工程值 | 含义 |
|---|---|---|---|
| `PIN_CONFIG` 0x0A4 | b1-0 | `01b` | `SPEED_MODE = PWM` |
| `PERI_CONFIG1` 0x0AA | b9 | `0` | `SPEED_RANGE_SEL = 325Hz~100kHz` |
| `DEVICE_CONFIG2` 0x0A8 | b15-14 | `11b` | `SLEEP_ENTRY_TIME = 200 ms` |
| `CLOSED_LOOP4` 0x08E | b13-0 | `3600` | `MAX_SPEED = 600 Hz × 6` |

改 `MAX_SPEED` 就会同步改变"占空比 → 转速"的比例，接口层代码不用动。

## 9. 常见问题

| 现象 | 排查 |
|---|---|
| 给 PWM 完全不转 | ① fPWM 是否 < 325 Hz；② 占空比是否 ≤1%；③ VM 是否上电；④ nFAULT 是否被拉低（有故障）；⑤ 器件是否在休眠且 PWM 未唤醒 |
| 转速比预期低/高 | 检查 `MAX_SPEED` 与电机极对数；占空比是否被主机侧限幅 |
| 转一下就停、反复重启 | 无感启动失步。看 nFAULT 后的故障码：`ABN_BEMF`/`MTR_LCK` = 启动打滑，`HW_LOCK_LIMIT` = 启动电流冲顶 |
| 转速上不去、异响 | 输出载波太低导致电流纹波过大（本电机 <50 kHz 会报 `HW_LOCK`） |
| 一给速度就掉电 | 母线供电能力不足，或跳了过流保护 |

## 10. 快速验证清单

1. SPEED 给 **5 kHz / 3.3V / 20%** → 电机应缓慢启动并稳定在 **≈1029 RPM**
2. FG 引脚用示波器看：频率 = 机械转速/60 × 极对数（本电机 7）
3. 占空比从 20% 逐步加到 100%，转速应线性跟随，nFAULT 保持高电平
4. 占空比给到 **0%**，等 200 ms → 板载指示灯灭（进入休眠）；再给 20% → 3~5 ms 后自动唤醒
5. 占空比给 **1%** → 电机不转、指示灯保持亮（器件不休眠，I2C 仍可用）
