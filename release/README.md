# 产线配置烧录固件（ESP32-C3）

把 MCF8315D 芯片的完整配置写进片内 EEPROM。**一次接一片，接上就烧，烧完提示换片。**

本固件的配置内容与调试定稿版完全一致：

- PWM 载波 **55 kHz + ±5% 抖动**（降噪）
- 转速上限 **600 Hz 电频率 ≈ 5143 RPM**
- 电流：对齐 2.187A / 开环 2.812A / 闭环 2.812A / 堵转 3.75A
- 启动：对齐 1s → 开环 250Hz/s → 15% 换相，ISD + 重同步开启
- 电机参数：R=0x74、L=0x02、Ke=0x0A、速度环 Kp/Ki=1

---

## 文件

| 文件 | 烧录地址 | 用途 |
|---|---|---|
| `mcf8315d_provisioner_full.bin` | **0x0** | 完整镜像（bootloader + 分区表 + 程序），一次烧完，**推荐** |
| `mcf8315d_provisioner_app.bin` | 0x10000 | 只更新程序（芯片里已有 bootloader 时用） |

### 烧录命令

```bash
# 完整镜像（推荐）
esptool.py --chip esp32c3 --port COMx --baud 921600 \
    write_flash 0x0 mcf8315d_provisioner_full.bin

# 只更新程序
esptool.py --chip esp32c3 --port COMx --baud 921600 \
    write_flash 0x10000 mcf8315d_provisioner_app.bin
```

图形工具（Flash Download Tool / ESP32 Flash Download Tool）选 ESP32-C3，
地址填 `0x0`，选 `mcf8315d_provisioner_full.bin` 即可。

## 治具接线

| ESP32-C3 | 目标板 |
|---|---|
| GND | GND |
| GPIO7 | SDA（器件的 SDA） |
| GPIO8 | SCL（器件的 SCL） |
| **GPIO5** | **SPEED/WAKE** |

**SPEED 这根必须接。** 悬空时器件 200ms 后进入休眠 → AVDD 关闭 → I2C 上拉失效 →
扫描永远扫不到器件。本固件在 SPEED 上常驻输出 1% 占空比 PWM 保活
（DUTY_CMD 仍为 0，电机不会转）。

I2C 上拉（5.1k）在目标板上，挂 AVDD，不需要治具提供。
目标板必须给 **VM 供电**，器件的 AVDD/DVDD 由内部从 VM 生成。

---

## 操作流程

1. 给 ESP32 上电（USB 即可），打开串口 **115200**
2. 接上第一片目标板（VM 上电）→ 自动开始烧录
3. 看到 `>>> 结果：成功 PASS <<<` 后**断开这一片**
4. 工具检测到器件移走，打印"请放下一片"
5. 接下一片 → 自动重复

> 同一片不会被重复写：烧完进入"等移走"状态，必须检测到连续 3 次无应答才认定换片，
> 避免白白消耗 EEPROM 寿命（2 万次）。

## 输出判读

成功：

```
========================================
 检测到器件 0x01，开始烧录第 1 片
========================================
   ... 65 项配置 OK ...
   写 0x8A500000 -> 0xEA，等待 750ms ...
   命令已归零。
   EEPROM 校验通过（无 CRC / parity 故障）。
>>> 结果：成功  PASS  <<<
```

失败时 `>>> 结果：失败 FAIL <<<`，并在上面几行给出原因（配置项 FAIL / EEPROM 校验报错 /
MAX_SPEED 回读不符），常见原因：

| 现象 | 原因 |
|---|---|
| 一直扫不到器件 | SPEED 没接 / 器件休眠；VM 没上电；I2C 接线或上拉缺失 |
| EEPROM 校验报错 | 器件供电不稳；EEPROM 已损坏 |
| 配置项 FAIL | I2C 通信中途掉线 |

## 注意

- 烧录完成后 **EEPROM 内容立即写好了**，影子寄存器也已是新配置；
  "断电重启生效"指的是器件下次上电从 EEPROM 载入
- 固件版本：`ESP32C3-MCF8315D v2.0.0`（批量烧录模式）
- 串口命令仍然可用：`p` 状态、`f` 故障、`d` 寄存器、`P` 手动烧录、`h` 帮助
